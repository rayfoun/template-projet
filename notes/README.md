# Notes

Recherches, brouillons, comparatifs, explications : tout ce qui sert à **comprendre** avant ou pendant la production.

- Un fichier par sujet, nommé `AAAA-MM-JJ-sujet.md`.
- Chaque inconnue de « Risques » dans `PROJECT.md` donne une note ici, terminée par une conclusion de 3 à 5 lignes.
- Si tu ne peux pas résumer la note avec tes mots, la compréhension n'est pas finie.
- Les définitions courtes vont dans `GLOSSAIRE.md`, avec un lien vers la note si besoin.
