# Recettes

Vide au départ, et c'est voulu. Une recette naît quand tu as fait **deux** projets du même type
(N8N, agent IA, app web, analyse de données…) et que ta rétro montre ce qui s'est répété.

Au cadrage, `/cadrer` (ou toi) regarde ici si une recette correspond au projet.

## Format d'une recette : `recettes/<type>.md`

```markdown
# Recette : <type de projet>

_Issue de : <projet 1>, <projet 2> · Mise à jour : AAAA-MM-JJ_

## Où vit le travail
Dossiers à créer et ce qu'ils contiennent.

## Comment je vérifie que ça marche
Commandes ou démarche de test.

## Qu'est-ce que je livre
Forme du livrable, éléments à ne pas oublier.

## Section « Projet » de CLAUDE.md
Installer / Lancer / Vérifier / Livrer, prêts à copier.

## Tâches types de M0
- [ ] ...

## Pièges déjà rencontrés
- ...
```
